## Installer le launcher de Casteria

1. Télécharge **Casteria-Installation.exe** (juste en dessous, dans « Assets »).
2. Ouvre-le. Le launcher s'installe tout seul, sans rien te demander, et s'ouvre. Un raccourci **Casteria** apparaît
   sur ton Bureau et dans le menu Démarrer.
3. Choisis ton pseudo, puis clique sur **JOUER** : le launcher prépare le jeu (la première fois, quelques minutes),
   puis t'emmène directement sur le serveur. Tape `/login` et ton mot de passe dans le jeu.

### « Windows a protégé votre ordinateur »

La première fois, Windows peut afficher cet écran bleu, parce que le launcher est nouveau et encore peu téléchargé.
Ce n'est pas un virus : c'est l'avertissement habituel pour un programme que Windows ne connaît pas encore.

1. Clique sur **Informations complémentaires** (le petit lien sous le texte).
2. Vérifie que la ligne « Application » dit bien **Casteria-Installation.exe**.
3. Clique sur **Exécuter quand même**.

Ton navigateur peut aussi prévenir que le fichier est « peu téléchargé » : choisis **Conserver**.

Tu n'auras à le faire qu'une fois : ensuite, le launcher se met à jour tout seul, sans rien retélécharger.

### Bon à savoir

- Le launcher ne touche jamais à ton dossier `.minecraft` : tu peux garder ton autre launcher.
- Il ne te demande jamais ton mot de passe : tu le tapes dans le jeu, avec `/login`.
- Pour le désinstaller : Paramètres de Windows, Applications, **Casteria**, Désinstaller. Tout ce qu'il a installé
  part avec lui (ton île et tes jetons restent sur le serveur, à ton pseudo).
