## Sur Windows

1. Télécharge **[Casteria-Installation.exe](https://github.com/guerrinflorian/casteria-mc/releases/download/installateur/Casteria-Installation.exe)**.
2. Ouvre-le. Le launcher s'installe tout seul, sans rien te demander, et s'ouvre. Un raccourci **Casteria** apparaît sur ton Bureau et dans le menu Démarrer.
3. Choisis ton pseudo, puis clique sur **JOUER**.

La première fois, Windows peut afficher un écran bleu, **« Windows a protégé votre ordinateur »**. Ce n'est pas un virus : Windows prévient pour tout nouveau programme. Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**. Si ton navigateur dit que le fichier est « peu téléchargé », choisis **Conserver**.

## Sur Mac

Il faut **macOS 13 ou plus récent** (tu le vois dans **À propos de ce Mac**).

1. **Choisis le bon fichier.** Ouvre le menu Pomme (en haut à gauche), puis **À propos de ce Mac** :
   - si tu lis **« Puce Apple »** (M1, M2, M3...), prends **[Casteria-mac-apple-silicon.zip](https://github.com/guerrinflorian/casteria-mc/releases/download/installateur/Casteria-mac-apple-silicon.zip)** ;
   - si tu lis **« Processeur Intel »**, prends **[Casteria-mac-intel.zip](https://github.com/guerrinflorian/casteria-mc/releases/download/installateur/Casteria-mac-intel.zip)**.
2. **Installe-le.** Double-clique sur le fichier téléchargé : **Casteria** apparaît à côté. Fais-le glisser dans le dossier **Applications**.
3. **Ouvre-le une première fois.** Ton Mac le bloque, parce qu'il ne le connaît pas encore : c'est normal, et ça n'arrive qu'une fois.
   - Double-clique sur **Casteria**. Un message dit qu'Apple n'a pas pu le vérifier : clique sur **Terminé** (pas sur « Placer dans la corbeille »).
   - Ouvre **Réglages Système** (menu Pomme), puis **Confidentialité et sécurité**. Tout en bas, à côté de « Casteria a été bloqué », clique sur **Ouvrir quand même**, puis tape le mot de passe de ton Mac.
   - Un dernier message s'ouvre : clique encore sur **Ouvrir quand même**.

Ensuite, Casteria s'ouvre comme n'importe quelle application.

## Sur Linux

Il faut un Linux récent : **Ubuntu 24.04** ou plus récent, **Linux Mint 22**, **Debian 13**, **Fedora 40**, **Arch** ou **Manjaro**. Sur un Linux plus ancien, le launcher s'ouvre, mais le jeu ne peut pas démarrer.

### Ubuntu, Linux Mint, Debian, Pop!_OS, Zorin : le fichier .deb

1. Télécharge **[Casteria-Linux-x86_64.deb](https://github.com/guerrinflorian/casteria-mc/releases/download/installateur/Casteria-Linux-x86_64.deb)**.
2. Double-clique dessus : la logithèque s'ouvre. Clique sur **Installer**, puis tape le mot de passe de ton ordinateur.
3. Casteria est dans le menu des applications.

Rien ne s'ouvre au double-clic ? Fais un clic droit dans le dossier du fichier, puis **Ouvrir dans un terminal**. Copie cette ligne, puis appuie sur Entrée (il te demande le mot de passe de ton ordinateur) : `sudo apt install ./Casteria-Linux-x86_64.deb`

### Arch, Manjaro, EndeavourOS : le paquet Arch

1. Télécharge **[Casteria-Linux-x86_64.pacman](https://github.com/guerrinflorian/casteria-mc/releases/download/installateur/Casteria-Linux-x86_64.pacman)**.
2. Fais un clic droit dans le dossier du fichier, puis **Ouvrir dans un terminal**. Copie cette ligne, puis appuie sur Entrée (il te demande le mot de passe de ton ordinateur) : `sudo pacman -U Casteria-Linux-x86_64.pacman`
3. Casteria est dans le menu des applications.

### Les autres Linux (Fedora...) : le fichier .tar.gz

1. Télécharge **[Casteria-Linux-x86_64.tar.gz](https://github.com/guerrinflorian/casteria-mc/releases/download/installateur/Casteria-Linux-x86_64.tar.gz)**, puis ouvre-le (clic droit, **Extraire ici**).
2. Dans le dossier **Casteria-Linux-x86_64**, double-clique sur **installer.sh** (ou clic droit, **Lancer comme un programme**).
3. Casteria est dans le menu des applications, et le launcher s'ouvre. Pas besoin de mot de passe.

Rien ne se passe au double-clic ? Fais un clic droit dans ce dossier, puis **Ouvrir dans un terminal**. Copie cette ligne, puis appuie sur Entrée : `./installer.sh`

### Pour ceux qui connaissent : l'AppImage

Télécharge **[Casteria-Linux-x86_64.AppImage](https://github.com/guerrinflorian/casteria-mc/releases/download/installateur/Casteria-Linux-x86_64.AppImage)**, autorise-le à se lancer, puis double-clique dessus. Il ne s'ouvre pas ? Prends plutôt le .deb ou le .tar.gz.

## Ensuite, dans le jeu

La première fois, tape `/register` puis un mot de passe que tu inventes (4 lettres ou chiffres au moins). Invente-le rien que pour Casteria : jamais celui de ton compte Microsoft ou de ta boîte mail. Les fois suivantes, tape `/login` puis ce mot de passe. Tu as une minute pour le faire.

- Le launcher ne touche jamais à ton dossier Minecraft habituel : tu peux garder ton autre launcher.
- Il ne te demande jamais ton mot de passe : tu le tapes dans le jeu.
- Garde toujours le même pseudo, avec les mêmes majuscules : ton île et tes jetons sont à ce nom.

## Si ça ne marche pas

Le launcher écrit ce qui ne va pas sous le bouton **JOUER**. Cherche ci-dessous la phrase que tu vois.

### Pour installer

**Windows bloque le fichier** (écran bleu, antivirus, ou « peu téléchargé » dans le navigateur) : c'est normal pour un nouveau programme. Écran bleu : **Informations complémentaires**, puis **Exécuter quand même**. Navigateur : **Conserver**. Antivirus : ouvre ton antivirus et remets le fichier (le bouton s'appelle souvent **Restaurer** ou **Autoriser**).

**Le Mac dit qu'Apple n'a pas pu vérifier Casteria** : suis l'étape 3 de la partie Mac, plus haut.

**Le Mac dit que « Casteria est endommagé »** : ne le mets pas à la corbeille. Retélécharge le fichier et recommence l'installation.

**Linux : le fichier ne s'ouvre pas** : prends le .deb (Ubuntu, Mint, Debian) ou le .tar.gz, plutôt que l'AppImage.

**« Ton Linux est trop ancien pour lancer le jeu : il faut Ubuntu 24.04, Linux Mint 22 ou plus récent. »**, avec **« Le jeu ne peut pas se lancer sur cet ordinateur. »** : le launcher s'ouvre, mais ton Linux est trop ancien pour le jeu. Il faut le mettre à jour.

**« Il manque un morceau du launcher : réinstalle-le. »**, ou **« Une nouvelle version du launcher demande de retélécharger son installation. »** : retélécharge le launcher sur cette page et installe-le de nouveau. Ton île et tes jetons ne bougent pas : ils sont sur le serveur.

### Avant d'entrer sur le serveur

**« Première préparation du jeu (une seule fois, environ une minute)... »** : la première fois, le launcher télécharge le jeu. Ça peut prendre quelques minutes, selon ta connexion internet. Ne ferme pas le launcher.

**« Impossible de joindre le serveur des mises à jour : vérifie ta connexion internet, puis réessaie. »**, ou **« Un fichier n'a pas pu être téléchargé : vérifie ta connexion internet, puis réessaie. »** : vérifie ton internet, puis clique encore sur **JOUER**.

**« Le serveur est fermé pour le moment, réessaie dans un instant. »** : le serveur est éteint (une mise à jour, souvent). Réessaie un peu plus tard.

**« Le jeu est encore ouvert : ferme-le, puis réessaie. »** : ferme la fenêtre de Minecraft, puis clique sur **JOUER**.

**Le launcher se ferme après « Redémarrer » et ne revient pas** : rouvre-le. Il s'est mis à jour, et ça n'arrivera plus.

**« Le jeu n'a pas pu démarrer : réessaie, et si ça recommence, préviens le staff sur Discord ou par un ticket sur le site de Casteria. »** : réessaie une fois. Si ça recommence, envoie aussi au staff le journal du jeu (voir **Le jeu a planté**, plus bas).

### Le pseudo et le mot de passe

**« Le serveur n'a pas accepté ce pseudo. Vérifie son orthographe (majuscules comprises), ou demande au staff de t'ajouter, sur Discord ou par un ticket sur le site de Casteria. »** : vérifie ton pseudo dans **Réglages**. S'il est juste, demande au staff.

**Ton île a disparu** : tu as sûrement changé une majuscule de ton pseudo (« Alex_12 » et « alex_12 » sont deux joueurs différents). Remets exactement ton ancien pseudo dans **Réglages** : ton île revient.

**« Tu n'as pas tapé ton mot de passe à temps. Relance le jeu, puis tape-le dans la minute : /register la première fois, /login ensuite. »** : relance le jeu, et tape ton mot de passe dès que tu arrives.

**Mot de passe oublié** : demande au staff (Discord ou ticket sur le site de Casteria).

**« Quelqu'un vient d'entrer sur Casteria avec ton pseudo, depuis un autre endroit. »** : si ce n'est pas toi, préviens tout de suite le staff (Discord ou ticket sur le site de Casteria).

### Pendant la partie

**« Le serveur redémarre ou s'est arrêté. Réessaie dans une minute. »** : attends une minute, puis clique encore sur **JOUER**.

**« Le serveur est complet pour le moment : réessaie dans quelques minutes. »** : une place va se libérer, réessaie bientôt.

**« La connexion avec le serveur a été coupée (internet ou serveur). Réessaie dans un instant. »**, ou **« La connexion au serveur n'a pas abouti. Réessaie dans un instant. »**, ou **« Impossible de joindre le serveur : il est peut-être fermé, ou ta connexion internet est coupée. Réessaie dans un instant. »** : vérifie ton internet, puis réessaie un peu plus tard.

**Le jeu rame** : dans **Réglages**, monte un peu **La mémoire du jeu**. Si tu hésites, garde la valeur conseillée.

**« Le jeu a planté. Dans Réglages, clique sur Le journal du jeu (pour le staff), puis envoie le fichier le plus récent au staff, sur Discord ou par un ticket sur le site de Casteria. »** : relance le jeu. Si ça recommence, dans **Réglages**, clique sur **Le journal du jeu (pour le staff)** : un dossier s'ouvre. Envoie au staff le fichier le plus récent (la date est dans son nom).

### Rien de tout ça ?

Contacte un membre du staff sur Discord, ou fais un ticket sur le site de Casteria. Dis quel ordinateur tu as (Windows, Mac ou Linux), et recopie la phrase que le launcher a écrite.

## Désinstaller

- **Windows** : Paramètres, Applications, **Casteria**, Désinstaller.
- **Mac** : fais glisser **Casteria** du dossier Applications vers la corbeille.
- **Linux** : désinstalle Casteria depuis ta logithèque, comme une autre application. Sinon, copie la ligne de ton fichier dans un terminal, puis appuie sur Entrée :
  - le .deb : `sudo apt remove casteria`
  - le paquet Arch : `sudo pacman -R casteria`
  - le .tar.gz : `~/.local/share/casteria-launcher/installer.sh --desinstaller`
  - l'AppImage : supprime simplement le fichier.

Ton île et tes jetons restent sur le serveur, à ton pseudo : tu les retrouves en réinstallant le launcher.
